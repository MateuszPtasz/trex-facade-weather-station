# Images

Public photographs and screenshots used by the project documentation. Before
publishing any replacement, verify that it does not show Wi-Fi passwords,
private SSID, local network addresses, precise location or other personal data.

## Included assets

- `station-enclosure-power-module.jpeg` — RainPoint enclosure and the
  MT-series module used to provide a stable 5 V supply.
- `station-internal-esp32-c3-bme.jpeg` — assembly view with the ESP32-C3 Mini
  controller and BME pressure sensor module.
- `station-light-sensor.jpeg` — close-up of the dedicated ambient-light
  sensor.
- `web-config.png` — Wi-Fi configuration page, without saved credentials or a
  selected network.
